Краткие теоретические сведения:
• Условный оператор if-elif-else: Используется для проверки логических условий и ветвления алгоритма. Конструкция elif позволяет связывать несколько последовательных проверок без добавления лишней вложенности отступов. Блок else выполняется, если ни одно из условий не подтвердилось. Обязательным синтаксическим правилом является использование двоеточия
(:) и строгое соблюдение отступов (4 пробела).
• Цикл while: Выполняет блок выражений до тех пор, пока проверяемое условие истинно (True). Для экстренного выхода из цикла применяется оператор break, а для перехода к следующей итерации — continue. При естественном завершении цикла выполняются команды из необязательного блока else.
• Цикл for..in и функция range(): Осуществляет перебор элементов последовательности (списков, строк или диапазонов). Встроенная функция range(start, stop, step) генерирует арифметическую прогрессию чисел, не включая верхнюю границу stop.
• Пользовательские функции (def): Представляют собой многократно используемые блоки кода с собственным именем. Функция объявляется с помощью ключевого слова def, принимает параметры и возвращает результаты вычислений оператором return. Строки документации docstrings (в тройных кавычках) размещаются сразу после заголовка функции для описания ее назначения.


Задание:
Вариант 4. Расход топлива турбины.
Разработать функцию calculate_turbine_fuel(p_start=10, p_end=100, p_step=10). В цикле for по диапазону нагрузок P рассчитывать удельный расход: при P < 40 МВт q=0.25 кг/кВт·ч, при P >= 40 МВт q=0.21 кг/кВт·ч. Функция должна возвращать суммарный расход топлива.
Код программы:
def calculate_turbine_fuel(p_start=10, p_end=100, p_step=10):
    """
    Функция рассчитывает суммарный расход топлива турбины в заданном диапазоне нагрузок.
    Параметры:
    p_start (int/float): Начальная нагрузка (МВт)
    p_end (int/float): Конечная нагрузка (МВт)
    p_step (int/float): Шаг изменения нагрузки (МВт)

    """
    total_fuel = 0.0 #Создание переменной для общего кол-ва расхода топлива 
    # Цикл for перебирает нагрузки от 10 до 100 с шагом 10
    for P in range(p_start, p_end + 1, p_step):
        #Рассчитываем удельный расход по диапозону нагрузок
        if P < 40:    # Мвт
            q = 0.25  # кг/кВт*ч
        else:
            q = 0.21  # кг/кВт*ч
        # Рассчитываем расход топлива для текущей нагрузки (В МВт * 1000 = кВт)
        current_fuel = P * 1000 * q
        # Добавляем расход текущей нагрузки к  общщему
        total_fuel += current_fuel
        # Вывод расхода для конкретной нагрузки
        print(f"Нагрузка P = {P} МВт; Удельный расход q = {q} кг/кВт*ч. Расход: {current_fuel:.2f} кг")
    # Возвращаем суммарный расход топлива
    return total_fuel
#Tестирование функции
print("Расчет суммарного расхода топлива турбины:")
# Вызываем функцию и сохраняем результат в переменную
result = calculate_turbine_fuel()
print(f"Суммарный расход топлива за весь цикл: {result:.2f} кг")
