Краткие теоретические сведения:
Язык Python является интерпретируемым. При первом запуске код транслируется в промежуточный байт-код и выполняется виртуальной машиной. Переменные представляют собой ссылки (имена), связанные с объектами в динамической памяти. Отступы (ровно 4 пробела) обязательны и служат для группировки блоков кода. Метод format() позволяет выполнять форматирование в соответствии со спецификацией PEP 3101.
Например, выражение '{0:.3f}'.format(pi) форматирует вещественное число с точностью до трех знаков после запятой. Вместо метода format() можно использовать f-строки.















Задание:
Вариант 4. Напишите скрипт, вычисляющий физическую величину по формуле. Все переменные должны быть динамически привязаны к значениям. Вывод результата осуществить с округлением вещественной части до 4 знаков после запятой. Исходные параметры ввести с помощью функции input().
Физическая величина / Формула: Период колебаний пружинного маятника: T = 2 * pi * sqrt(m / k)
Исходные параметры (константы): pi = 3.14159, m = 0.45, k = 150.0

Код программы:
#Ввод данных, команда input()
# Функция float() принимает дробное число
m = float(input("введите массу:m= "))
k = float(input("введите жесткость пружины:k= "))
pi = 3.14159 # Обозначаем константу, чтобы пользователь не вводил ее самостоятельно.
T = 2*pi*(m/k)**(1/2) #Программа подставляет значения в формулу, происходит вычисление
# Конструкция {T:.4f} выводит переменную T как число, округлив его до 4 знаков после запятой.
# Для вывода данных на экран используется команда print()
print(f"Период колебаний пружинного маятника T = {T:.4f}")

Результат:
введите массу:m= 0.45
введите жесткость пружины:k= 150.0
Период колебаний пружинного маятника T = 0.3441
