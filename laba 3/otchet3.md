# Краткие теоретические сведения
Модульная организация программ и системные модули
Модуль в Python представляет собой отдельный файл с расширением .py, содержащий определения функций, переменных и классов. Модульная архитектура обеспечивает повторное использование кода и декомпозицию сложных программных комплексов.

Импорт модулей: для подключения встроенных или внешних модулей используется оператор import module. Для импорта конкретных функций используется from module import function.

Точка входа __name__: при импорте модуля весь его код исполняется один раз. Чтобы отделить код тестирования от используемого функционала, применяется точка входа с проверкой специальной переменной if __name__ == '__main__':.

Системный модуль sys: модуль sys предоставляет доступ к параметрам среды исполнения. В частности, список sys.argv содержит аргументы командной строки, переданные скрипту при запуске.

Базовые структуры данных
Python содержит четыре основные встроенные структуры данных, предназначенные для группировки и обработки наборов элементов:

Списки (list): упорядоченные динамические массивы элементов произвольных типов ([]). Являются изменяемыми (mutable), что позволяет добавлять (append()), сортировать (sort()) и удалять (pop(), remove(), del) элементы.

Кортежи (tuple): упорядоченные неизменяемые (immutable) последовательности элементов (()). Кортежи применяются для защиты данных от случайной модификации и возврата нескольких значений из функций.

Словари (dict): ассоциативные массивы, хранящие пары «ключ: значение» ({}). Ключи должны быть уникальными и неизменяемыми объектами (строки, числа, кортежи).

Множества (set): неупорядоченные коллекции уникальных элементов. Множества поддерживают математические операции: объединение (|), пересечение (&), разность (-).

Индексация и операции срезов
Последовательности (списки, кортежи, строки) поддерживают обращение к элементам по индексам и получение фрагментов с помощью срезов. Синтаксис среза имеет вид [start:stop:step], где start — начальный индекс (включительно), stop — конечный индекс (не включительно), step — шаг извлечения элементов.

Отрицательные индексы: отрицательные индексы отсчитываются от конца последовательности: -1 соответствует последнему элементу.

Разворот последовательности: срез со значением шага -1 (например, sequence[::-1]) выполняет быстрый разворот последовательности в обратном порядке.

Системная переменная sys.argv в Python
sys.argv — это специальная переменная (список строк) из системного модуля sys в языке Python, которая содержит аргументы командной строки, переданные программе при её запуске из консоли.

Структура и индексация списка sys.argv:

sys.argv[0] — всегда содержит имя самого запускаемого файла программного скрипта (или путь к нему).

sys.argv[1], sys.argv[2], … — хранят текстовые параметры и флаги, переданные программе через пробел после её имени при консольном запуске.

Маршрутизация и декодирование кадров Modbus/PLC
Физический процесс / инженерное явление:
Промышленный контроллер опрашивает ведомые устройства по протоколу Modbus RTU. Из
телеметрического бинарного кадра необходимо извлекать адреса, коды функций и данные, а
также фильтровать незарегистрированные адреса устройств.
Задачи модуля (variant_mod.py):
1) parse_frame(frame_list) — срезами извлекает адрес ведомого [0], код функции [1] и байты
данных [2:-2];
2) filter_known_slaves(slave_id, allowed_set) — проверяет принадлежность адреса множеству
allowed_set;
3) format_telemetry_dict(device_id, reg_dict) — формирует сводный словарь состояния регистров.
   
Требования к программе main.py:
1) Считать проверяемый slave_id из sys.argv[1] (дефолт 5).
2) Задать кадры Modbus, разобрать их, проверить по множеству разрешенных адресов и вывести
результат.
# Код программы
Файл variant4_mod.py (пользовательский модуль)

```
""""
Модуль маршрутизации и декодирования кадров Modbus/PLC.
"""

def parse_frame(frame_list):
    """
    Извлекает адрес, код функции и данные из кадра.
    """
    if len(frame_list) < 4:
        raise ValueError("Кадр слишком короткий.")

    slave_id = frame_list[0]
    function_code = frame_list[1:2]
    data_bytes = frame_list[2:-2]

    return slave_id, function_code, data_bytes


def filter_known_slaves(slave_id, allowed_set):
    """
    Проверяет, есть ли адрес в разрешённом множестве.
    """
    return slave_id in allowed_set

def format_telemetry_dict(device_id, reg_dict):
    """
    Формирует словарь телеметрии.
    """
    return {
        "device_id": device_id,
        "registers": reg_dict,
        "status": "OK" if reg_dict else "NO_DATA"
    }

if __name__ == '__main__':
    print(" АВТОНОМНЫЙ ТЕСТ МОДУЛЯ ")
    test_frame = [5, 3, 0, 100, 0, 2, 180, 22]
    allowed = {1, 3, 5, 12}

    addr, func, data = parse_frame(test_frame)
    print(f"Адрес={addr}, Функция={func}, Данные={data}")
    print(f"Разрешён: {filter_known_slaves(addr, allowed)}")

Файл main4.py (главный скрипт)

```
import sys

#Импортируем наши функции из первого файла (variant4_mod.py)
from variant4_mod import filter_known_slaves, format_telemetry_dict, parse_frame


def main():
    # Чтение настроек из sys.argv (аргументов командной строки)
    if len(sys.argv) > 1:
        try:
            device_id = int(sys.argv[1])
        except ValueError:
            print("Ошибка: ID устройства должен быть числом. Используем 5 по умолчанию.")
            device_id = 5
    else:
        device_id = 5

    # Множество разрешенных адресов (для проверки)
    allowed_slaves = {1, 3, 5, 12}

    # Формируем тестовые данные (кадр Modbus)
    raw_frame = [device_id, 3, 0, 100, 0, 2, 180, 22]
    
    print(" СВОДНЫЙ ОТЧЕТ СИСТЕМЫ ТЕЛЕМЕТРИИ ")
    print(f"Запущен скрипт: {sys.argv[0]}")
    print(f"Анализируемый кадр: {raw_frame}")

    # Вызываем функции из модуля
    try:
        # Извлекаем данные
        addr, func, data = parse_frame(raw_frame)
        
        # Проверяем, разрешен ли адрес
        is_allowed = filter_known_slaves(addr, allowed_slaves)
        
        # Формируем словарь телеметрии
        telemetry = format_telemetry_dict(addr, data)
        
        # Выводим результат
        print("\n РЕЗУЛЬТАТ ДЕКОДИРОВАНИЯ ")
        print(f"Адрес устройства: {addr}")
        print(f"Код функции: {func}")
        print(f"Данные: {data}")
        
        if is_allowed:
            print("Статус адреса: РАЗРЕШЕН (устройство в белом списке)")
        else:
            print("Статус адреса: ЗАПРЕЩЕН (неизвестное устройство!)")
            
        print("\n СЛОВАРЬ ТЕЛЕМЕТРИИ ")
        for key, value in telemetry.items():
            print(f"  {key}: {value}")
            
        # Демонстрация среза: берем первые 2 байта данных
        print(f"\nПервые 2 байта данных (срез): {data[:2]}")
        
    except ValueError as e:
        print(f"\n ОШИБКА: {e}")

if __name__ == '__main__':
    main()
